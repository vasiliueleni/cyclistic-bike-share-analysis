# Data Sources

This project uses publicly available historical Divvy bike-share data.

Source: https://divvy-tripdata.s3.amazonaws.com/index.html

## Datasets

- Divvy Trips 2019 Q1
- Divvy Trips 2020 Q1

The original CSV files are not included in this repository due to their large file sizes.

To reproduce the analysis:
1. Download the two datasets from the official source.
2. Extract the CSV files.
3. Place them in this data folder.
4. Run the Jupyter Notebook.
